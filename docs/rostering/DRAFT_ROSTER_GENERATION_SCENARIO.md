# Draft Roster Generation Scenario

`ANAESTHESIA-DRAFT-ROSTER-GENERATION` creates ten fictional doctors and 28 days, records September 5 unavailability, September 8-10 leave, September 2 preferred work, and September 3 preferred off. It proves identical mutation-free previews, commits one generated batch, captures revision-1 reporting state, validates it, moves one generated assignment through the existing manual action, and captures revision-2 current state. Operational data rolls back unless `--keep-state` is supplied.

The scenario proves 180 required assignments at eight hours (1,440 staffing hours) against 1,360 combined target hours. The 80-hour unavoidable excess is distributed as eight hours per doctor, so every doctor has zero residual variance and 18 assignments. It records a weekend range of two, one honored preferred-work request, one violated preferred-off request, one explicitly available assignment, 179 assignments from provisional unspecified eligibility, and a maximum consecutive run of seven days. Consecutive reporting is descriptive only. The manual move makes one day under- and one day overstaffed without altering historical revision-1 quality.
