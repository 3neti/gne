# Foundation Workbook Compatibility

The foundation is compatible with later confirmed refinement; it does not reproduce or import the workbook.

| Workbook concept | Foundation support | Deferred seam | Confirmation required |
| --- | --- | --- | --- |
| Doctor identity | Yes | Identifier types/grouping | Employee-number meaning |
| Contracted hours | Yes | Period conversion | Yes |
| Roster-period required hours | Yes | Policy derivation | Yes |
| Daily assignment | Foundation seam | Segments | No for MVP |
| Work time segments | Optional fields | Multiple duties | Yes |
| On-call | No active rule | Duty vocabulary | Yes |
| Leave | Not yet | Requests slice | Legacy mapping |
| Overtime | No active rule | Duty vocabulary | Yes |
| Day classification | Yes | Holiday policies | Yes |
| Staffing row | No import | Explicit mapping | Yes |
| Spreadsheet import | No | Mapping specification | Yes |

Workbook rows, colours, suffixes, and unlabeled counts have no executable role. Clean fictional demonstration data is authored independently.
