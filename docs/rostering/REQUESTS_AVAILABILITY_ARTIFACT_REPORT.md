# Requests and Availability Artifact Report

The finalized scenario produces `report.json`, five linked HTML review pages plus a print source, and `anaesthesia-requests-and-availability.pdf`. The visual calendar renders four weekly bands and the separate matrix compares every doctor with every date. Each day exposes required, active, eligible, explicit, unspecified, unavailable, leave, preference, and conflict counts. Doctor sections preserve required hours and accepted request evidence. Conflict sections distinguish blocking errors from soft warnings.

The report is a disposable projection of fictional demonstration state. It is not canonical business source, an assignment roster, or evidence that optimization or generation exists. Run-specific checksums, PDF page count, byte length, and HTML aggregate fingerprint are recorded by the command and final slice report.
