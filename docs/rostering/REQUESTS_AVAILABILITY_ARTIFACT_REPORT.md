# Requests and Availability Artifact Report

The finalized scenario produces `report.json`, four linked HTML review pages plus a print source, and `anaesthesia-requests-and-availability.pdf`. The calendar summarizes required staffing, available/unavailable/leave counts, preferences, and conflicts for every date. Doctor sections preserve required hours and all accepted request dates. Conflict sections distinguish blocking errors from soft warnings.

The report is a disposable projection of fictional demonstration state. It is not canonical business source, an assignment roster, or evidence that optimization or generation exists. Run-specific checksums, PDF page count, byte length, and HTML aggregate fingerprint are recorded by the command and final slice report.
