# Anaesthesia Rostering Profile

This profile declares the small, confirmed policy vocabulary for the anaesthesia rostering foundation. Operational doctor and roster records are host-owned application state. The legacy workbook is discovery evidence, not an artifact import source.

Active scope is limited to explicit doctors, roster-period boundaries, one day per date, explicit headcount requirements, explicit doctor-period required hours, one counted primary daily assignment, and early lifecycle transitions. Requests, generation, multiple duties, call, overtime, payroll, publication, and workbook import remain deferred.
